# TrustedSite installation and verification

The known TrustedSite loader is included near the end of all three language pages:

```html
<script src="https://cdn.ywxi.net/js/1.js" async></script>
```

**Important:** The loader is not proof of certification, nor proof that it is associated with this GitHub domain. In your TrustedSite dashboard, add or authorize `melindabui.github.io` and confirm that the account and provider approve this hostname and script. If the provider issues a different unique snippet, replace the loader on all three pages. Only display a seal/badge after the dashboard confirms the required status. If you do not have approval, remove the loader until authorization.

TrustedSite is not a direct Google ranking factor.
